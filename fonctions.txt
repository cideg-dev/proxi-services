Edge cases / risques à couvrir
Upload de fichiers corrompus/volumineux → server should reject (size limit) and return 413/400.
Race condition sur demandes accept/decline : two artisans or requests — utiliser transaction and verify current status before update.
Token expiry (client side): refresh flow absent — ensure UX to re-login when token expired (401).
Socket disconnect/reconnect: preserve user mapping and re-emit user connected on reconnection.
DB schema mismatch in production vs dev → add migrations or version check on startup.
